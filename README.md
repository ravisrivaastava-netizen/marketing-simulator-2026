# Marketing P&L Simulator

## Status
🟡 Starter project — concept and framework stage

## Objective

Connect marketing decisions to commercial outcomes.

## Model

**Revenue → COGS → Gross Margin → Marketing/A&P → Trade Spend → Contribution**

## Scenarios

Examples:
- Price increase
- A&P increase
- Premium mix improvement
- New product launch
- Distribution expansion

## Output

Compare scenarios on:
- Revenue
- Gross margin
- Marketing investment
- Contribution
- Incremental economics

## Data

Use synthetic values until public datasets are introduced.
